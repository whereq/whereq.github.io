What it is

KeyToMarvel is the identity layer of the WhereQ Universe. It runs on Keycloak — the open-source IAM engine — and puts a themed front door on it: realms, clients, users and identity providers under one administration console.

The point is not a login form. It is that an account created once is an account everywhere: sign in to FlowDesk, sign in to chroniq.cc, sign in to the Atlas, and it is the same identity the whole way.

What it does

  • **Single sign-on** — one session across every application.
  • **Identity & access management** — realms, clients, roles and policies.
  • **Social login** — WeChat and Google identity providers.
  • **MFA** — a second factor where an application needs one.
  • **Profiles & relationships** — the user graph the products read.
  • **Self-service account portal** — users manage their own account, security and connected applications.

How it fits the universe

KeyToMarvel is the "WHO" of the universe — the one layer every other application calls before it does anything else. It is what lets qhaul.ca route a driver, chroniq.cc confirm a booking, and whereq.cloud meter an API key against the same person.

The theme itself is open source as `KeyToMarvel.com-theme`, so any Keycloak deployment can wear it.
