Tools reference

This page documents every tool exposed at mcp.whereq.cloud/mcp. The canonical source is the server’s list_tools() response — re-fetched at the playground.

Discovery

Section titled “Discovery”

discover()

Section titled “discover()”

Returns the full list of tools with their schemas. Use it to keep your agent’s tool list in sync with the server.

catalog()

Section titled “catalog()”

Browse the full data catalog.

Param Type Notes
category string Filter by category.
limit int Default 50, max 200.
lang string en or cn.

symbol_lookup(query)

Section titled “symbol_lookup(query)”

Fuzzy search across all symbols in the catalog.

Equities

Section titled “Equities”

equity_analyst(symbol)

Section titled “equity_analyst(symbol)”

Current price, mean target, rating breakdown. Requires the equities scope.

equity_holders(symbol)

Section titled “equity_holders(symbol)”

Top institutional + insider holders.

equity_earnings(symbol)

Section titled “equity_earnings(symbol)”

Upcoming + recent earnings.

equity_corporate_actions(symbol)

Section titled “equity_corporate_actions(symbol)”

Dividends, splits, buybacks.

Fundamentals

Section titled “Fundamentals”

fundamentals(symbol, period='quarterly', concept=None, as_of=None)

Section titled “fundamentals(symbol, period='quarterly', concept=None, as_of=None)”

As-reported financial statements. Pass concept (e.g. Revenues) for a single line item. Pass as_of=YYYY-MM-DD for point-in-time (lookahead-bias-free backtests).

equity_profile(symbol)

Section titled “equity_profile(symbol)”

Company description, sector, industry, employees, market cap, contact info.

Agent templates (Aquarius 2027.01 gallery)

Section titled “Agent templates (Aquarius 2027.01 gallery)”

The templates gallery is the second wedge on top of the MCP server. These tools let an MCP client browse, fetch, and install pre-built agent templates without leaving the tool surface. See /templates for the full reference.

agent_templates_featured()

Section titled “agent_templates_featured()”

Browse the curated 3 launch templates. Public, no auth. Returns the same shape as GET /v1/agent-templates/featured (slug, name, description, tools_used, use_count, fork_count). Cheap — 5-min cached.

agent_template_get(slug)

Section titled “agent_template_get(slug)”

Fetch a public template by slug (morning-market-brief, earnings-setup, squeeze-scan, etc.). Returns the full template — including the canonical prompt that the caller should paste into their own prompt. Bumps use_count for analytics.

agent_template_install(slug, client='claude_desktop')

Section titled “agent_template_install(slug, client='claude_desktop')”

One-click installer. Returns the JSON config fragment + a curl install command + the canonical starter prompt. Caller can either run(install_command) or merge config into the right file directly. Idempotent — re-running is a no-op merge. Bumps use_count. client is one of claude_desktop, cursor, vscode.
