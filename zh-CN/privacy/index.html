Privacy Policy — WhereQ

Effective date: 25 November 2026 Applies to: the WhereQ documentation site — whereq.github.io and www.whereq.com — and every page on it. Contact: WhereQ — googol.zhang@gmail.com

This is the privacy policy for the WhereQ documentation site. It is a plain Markdown file in the site's repository, and the version in the repository is the authoritative one.

The short version​

This site is a set of static pages. It has no accounts, no login and no database of users, and we run no analytics of our own — we do not know who is reading.

One thing can set a cookie or otherwise recognise your browser:

  • Comments. On a blog post you can leave a comment. The comment widget comes from Giscus, which stores the page you commented on in a public GitHub Discussion.

The search box is built for offline use: your query never leaves your browser.

What the site is​

Every page is a static file. There is no sign-in, no account, no profile and nothing to delete. If you read a page, the server that served it may write a line in its access log — that is the hosting provider's doing, not ours, and see Hosting and server logs below.

Advertising​

This site carries no advertising. Advertising in the family runs on PC Legends, the DOS games archive, which has a domain of its own and serves Google AdSense. The documentation hub is not part of that: no ad script is served on these pages, no advertising cookie is set here, and nothing is loaded from Google to show an ad.

If you came here from an ad, it was on the games site, and its own privacy policy is the one that describes it.

Comments​

On blog posts, the comment box is Giscus, which is a thin client for GitHub Discussions.

  • Giscus is loaded only when a comment box is on the page.
  • The page you are on is sent to Giscus and stored as the title of a GitHub Discussion — a public conversation on the whereq/whereq.github.io repository.
  • If you comment while signed in to GitHub, your GitHub account name and avatar are shown with the comment.
  • Giscus sets a cookie to keep your session. It does not set advertising cookies and it is not part of AdSense.

Please do not put personal information into a comment. A public Discussion is a public document.

Search​

The search box is docusaurus-search-local, which builds an index of this site's own pages into a static file that ships with the site. Your query is matched in your browser. It is not sent to us, to GitHub, to Google or to anyone else.

Hosting and server logs​

The site is published through GitHub Pages. Like any web host, GitHub processes the request in order to serve it, and its GitHub Privacy Statement covers the log data that results — an IP address, a user agent and a timestamp, kept for a limited period.

Other third parties​

Your rights​

If you are in the EEA, the UK or Switzerland, you have the right to ask us what we hold about you, to have it corrected or erased, to object to processing based on legitimate interests, to restrict it, to data portability, and to withdraw consent at any time. Where we hold no personal information about you at all — which is the case for everything except the record of a comment you chose to leave — there is nothing to withdraw.

If you are in California or elsewhere with similar laws, you have the right to know what personal information is collected and disclosed, to request deletion, to correct it, to opt out of its sale or sharing, and to limit the use of sensitive personal information. Where we do not collect your personal information in the first place, there is nothing to request or delete.

To exercise any of these rights, write to googol.zhang@gmail.com. You also have the right to complain to your local data protection authority, for example the ICO in the UK.

A request about advertising is about the games site rather than this one, and is best made through My Ad Center and Ads Settings. We will still help you with anything that concerns this site itself.

International transfers​

This site is hosted in the United States, and the comment widget is served by GitHub. If you leave a comment, GitHub may process your data in whichever country it operates from — GitHub's privacy statement explains the safeguards it relies on.

Children​

This site is a technical blog and is not directed at children. We do not knowingly collect personal information from children, and no part of it is aimed at them.

Security​

There is no account to steal and no database to breach: the site is static files. What can be exposed is limited to what you write in a public comment, so treat a comment as public.

Changes to this policy​

If this policy changes, the new text is committed to the site repository together with the change that caused it, and the effective date at the top is updated.
