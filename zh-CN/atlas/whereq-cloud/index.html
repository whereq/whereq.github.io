What it does
  • A versioned, metered REST API over every dataset it owns, with cursor pagination, ETag caching and per-key scopes.
  • A hosted MCP server — 80 tools over stdio and streamable HTTP — so an agent can query the same data directly.
  • Scheduled collection from free and premium providers, with collection monitoring and anomaly detection.
  • Bilingual financial news and editorial (中文 / EN), hot rankings, quotes, and the economic calendar.
  • 22,000+ instruments tracked across 15 global exchanges, with 5.4M+ quotes stored.
  • Official Python and JavaScript SDKs, plus public endpoints that work without a key.

What it is

whereq.cloud is where the universe keeps its facts. It owns the shared schema, runs the collectors that fill it, and publishes it through one API. Everything else in the universe consumes that data instead of scraping the world separately.

The same platform carries the domains the products need: global equities and quotes, finance news, hot rankings, the macro calendar, and — beyond finance — geography, fuel prices, cost-of-living series, autos and industry directories.

How it fits the universe

whereq.cloud is a dependency, not a competitor. FlowDesk pulls its market data from the Data API; caijing.today reads the same published PostgreSQL schema contract through its own FastAPI. Because WhereQ owns the collection pipeline, the schema, the ingestion and the API version are one decision instead of three.

It is also the universe's AI surface: the MCP server is what lets an agent inside Cursor or Claude query live market data rather than a stale copy of it.
