Dazhi Zhang (Tony)

所有 DOS 程序唯一都认同的那一个接口​

有一件事是我没料到自己会在意，然后一旦在意就停不下来的。

1987 年的 DOS 游戏并不知道显卡是什么。它不知道鼠标存在，也不知道键盘有个缓冲区。它只认一件事：往栈里推一个数，执行 INT，机器就会回答。INT 10h，机器把一个字符画到屏幕上。INT 16h，机器交出一个按键。INT 33h，机器告诉你鼠标在哪、哪些按钮按着。

契约就这么多。1991 到 1994 年的每一个游戏都是照着它写的，而且它从来没有变过。

为了写这篇文章，我把 DOSBox 的中断层认真读了一遍。它是整个模拟器里建得最用心的部分之一——同时也是这个移植版被迫想得最多的部分之一，因为触摸屏不是鼠标，手机也不是 PC。

所以，地图在这里。

WhereQ-DOSBox interrupts: the map of every INT in the emulator

2026年11月19日 · 阅读需 14 分钟
Dazhi Zhang (Tony)

The one interface every DOS program agrees on​

Here is something I did not expect to care about, and then could not stop caring about.

A DOS game from 1987 does not know what a graphics card is. It does not know that a mouse exists, or that a keyboard has a buffer. It knows exactly one thing: it can ask the machine a question by pushing a number onto the stack and executing INT. INT 10h and the machine will put a character on the screen. INT 16h and the machine will hand over a keystroke. INT 33h and the machine will tell it where the mouse is and which buttons are down.

That is the whole contract. Every game from 1991 to 1994 is written against it, and it never changed.

I have been reading DOSBox's interrupt layer properly for this article, and it turns out to be one of the most carefully built parts of the emulator — and one of the parts this port has had to think about hardest, because a touch screen is not a mouse and a phone is not a PC.

So here is the map.

"Just now"​

You come back to the game after lunch. You tap the slot that said you saved it five hours ago. The game loads exactly where you left it — the boss, the health bar, the room you were in.

The music that stayed behind​

You freeze a game in the middle of a fight. The music is loud, the boss is doing something unpleasant, and you put the phone down to answer a message.

You come back two minutes later and load the state.

The fight is exactly where you left it — the sprites, the health bar, the position of the boss, all of it. The music, though, is somewhere else entirely: it was never frozen with the rest of the machine, so it carried on playing while everything else went back. And the beeping that was coming out of the PC speaker is still going on in the background, droning at nobody.

That was 1.0.0.9. The snapshot was very good, and it was missing the sound.

Remember when computers had no app stores, no touchscreens, no cloud accounts, and somehow we still managed to spend entire weekends playing games? 😂

We used to type commands like C:\GAMES\DOOM.EXE and consider ourselves computer experts.

Well, DOS never really left. It was just waiting for a smaller computer.

Today, we're taking a meaningful step in bringing that world to Android with WhereQ-DOSBox.

Not a DOS emulator running inside a browser. Not a remote desktop connecting to an old PC. It's a native Android application with the actual DOSBox emulator core running as a native library inside the APK.

And there's quite a bit more behind it.
