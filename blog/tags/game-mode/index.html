WhereQ-DOSBox 1.0.0.18：你早就有的那把键盘

November 24, 2026 · 9 min read
Dazhi Zhang (Tony)

抽屉里那把键盘​

大多数人的家里大概都有一把蓝牙键盘。它跟着平板、手机或者电视一起来，然后就一直躺在抽屉里——一块塑料，一百零四个键，手感比屏幕上任何一种"假装出来的键盘"都好。

和手机配对，它能用。

对一切都能用。

除了模拟器。

到这次发版之前，WhereQ-DOSBox 就是这样：配好蓝牙键盘，按一个键，什么也不会发生。不是"按错了键"，是什么都没有。内置的 SDL2 根本没有给 Android 键盘事件留通路，Java 层只喂输入法，原生那一侧一次按键事件都收不到。屏幕键盘是 app 唯一的输入通道，而想要一次按键的游戏，收到的是一根手指。

1.0.0.18 修好了它，而且是用这个 app 一贯的方式修：绝不另造一条输入通路。

现在，Android 的键码会被映射成 DOSBox 的键名，再通过屏幕键盘一直在用的那张原生表解析。两条路最后落到同一个扫描码、进入同一个 BIOS 缓冲区、从同一个 INT 09h 出去。Shift、Ctrl 和 Alt 一并带上，DOS 该看到的大写字母就都能看到。按住一个键时只有第一次按下会被转发——DOSBox 在 BIOS 定时器里自己会重复，多送一次事件就等于缓冲区里多一个扫描码。而打在启动脚本编辑器上的按键，永远不会跑到游戏里去。

这些是在模拟器里用真实按键事件验过的，不是用假动作糊过去的：字母和 Enter 能过《真人快打》的过场保护，F1 能开始游戏，F10 能打开它自己的选项菜单，方向键能移动菜单光标，也被游戏当作移动键接受。

抽屉里那把键盘，现在是 DOS 键盘了。

WhereQ-DOSBox 1.0.0.18: the keyboard you already own

November 24, 2026 · 10 min read
Dazhi Zhang (Tony)

The keyboard in the drawer​

Somewhere in most houses there is a Bluetooth keyboard. It came with a tablet, or a phone, or a television, and it has been sitting in a drawer ever since — a rectangle of plastic with a hundred and four keys that feel better than anything a screen can pretend to be.

Pair it with the phone and it works. For everything.

Except the emulator.

That was the state of WhereQ-DOSBox until this release: you paired the keyboard, you pressed a key, and nothing happened. Not "the wrong key" — nothing. The vendored SDL2 has no path for Android key events at all; the Java layer fed only the IME, and the native side never saw a single key event come in. The on-screen keyboard was the only input the app had, and a game that wanted a keypress got a finger instead.

1.0.0.18 fixes that, and it fixes it the way the app does everything else: by refusing to invent a new input path.

An Android key code is now mapped to a DOSBox key name, and that name is resolved through the same native table the on-screen keyboard already used. Both roads end in the same scancode, in the same BIOS buffer, behind the same INT 09h. Shift, Ctrl and Alt are carried along, so DOS sees the capital letters it should. Only the first press of a held key is forwarded — DOSBox does its own auto-repeat in the BIOS timer, and every extra event would be one more scancode in the buffer. And a keystroke aimed at the launch-script editor never reaches the game, which is the one thing that had to stay true.

Checked in the emulator with real key events, not with a mock: the letters and Enter pass the copy protection of Mortal Kombat, F1 starts the game, F10 opens its own options menu, and the arrow keys move the menu cursor and are accepted as the game's movement keys.

The keyboard in the drawer is a DOS keyboard now.

WhereQ-DOSBox 1.0.0.15：给拇指一个掌机

November 20, 2026 · 12 min read
Dazhi Zhang (Tony)

一根拇指终究不够用​

在手机上玩 DOS 游戏，总有那么一个瞬间：游戏不再像游戏，倒像一场手指的杂技。

你双手捧着手机，游戏却同时要你做三件事：向左，开火，跳跃。屏幕键盘拿来敲 MOUNT C . 很顺手，拿来玩游戏就很难受——一只拇指按在方向键上，另一只必须离开方向键去够字母 B，就那么一两秒，而带计时的游戏不会给你这一两秒。

于是你只挑那些单手能玩的游戏；那些要一只手按住方向、另一只手开火的作品，你干脆不碰。为打字而生的键盘，打字足够好，当手柄却不够。

1.0.0.15 给这块键盘添了第二张脸。

WhereQ-DOSBox 1.0.0.15: a console-style gamepad for your thumb

November 20, 2026 · 12 min read
Dazhi Zhang (Tony)

One thumb was never going to be enough​

There is a moment in every DOS game played on a phone where the game stops being a game and becomes a dexterity test.

You are holding the phone in two hands, and the game wants three things at once: go left, fire, jump. The on-screen keyboard is a good way to type MOUNT C . and a bad way to play that. One thumb stays on the arrows; the other one has to leave them to find the letter B, and for a second — a second that a game with a timer does not give you — nobody is steering.

So you play the games you can finish with one thumb, and you do not play the others. A keyboard built for typing is a fine typewriter and a poor controller.

1.0.0.15 gives that keyboard a second face.

WhereQ-DOSBox: a DOS machine in your pocket

November 20, 2026 · 16 min read
Dazhi Zhang (Tony)

The picture in the middle of my phone is 4:3, with black bars on either side — and those bars are not wasted, they hold the keyboard. The picture is a blue DOS banner and a prompt:

C:\>

The cursor blinks. It does not explain itself, and it does not need to.

This is a 1994 machine — a 486, a sound card, a two-button mouse — and it fits in one hand. Everything I used to type into it still works: cd, dir, copy, mount c .. It works because it is the same machine: DOSBox r4305 running as a native library inside the APK, not in a browser tab, not in a WebView. Native code, in your pocket, at native speed.
